# AI Editing Rules

SalesKit AI의 우측 초안은 생성 후 사용자가 직접 수정하거나, AI 수정 요청으로 다듬을 수 있어야 한다.

## 기본 원칙

- 사용자가 수정한 현재 본문을 기준으로 편집한다.
- 원본 생성 결과를 다시 덮어쓰지 않는다.
- 메일 구조는 유지한다.
- 요청이 애매하면 전체를 바꾸지 말고 톤과 문장 일부만 조정한다.

## 지원해야 할 수정 요청

### 더 정중하게

변경 방향:

- 단정적인 표현을 완화
- "조심스럽게", "검토에 도움이 되실 만한", "부담 없는 범위에서" 같은 표현 사용

### 더 짧게

변경 방향:

- 각 섹션 문장을 1~2개로 축약
- 중복되는 시장 설명 제거
- CTA는 유지

### 미팅 제안을 강하게

변경 방향:

- "가능하시면"보다 구체적인 일정 요청
- "이번 주 또는 다음 주 중 15분"처럼 행동을 명확히 제안

### 진단 결과를 부드럽게

변경 방향:

- "문제", "부족", "시급" 같은 표현을 완화
- "개선 여지", "더 선명하게 만들 수 있음", "보완 가능성" 사용

### 대표자용으로

변경 방향:

- 짧고 의사결정 중심
- 비용, 리소스, 성과 관리, 리스크 중심

### 실무자용으로

변경 방향:

- 실행 과정, 업무 부담, 반복 작업 감소 중심
- 너무 임원 보고서처럼 쓰지 않음

## 금지 표현

- 성과 보장
- 무조건
- 최저가
- 100% 개선
- 반드시 1위
- 확인되지 않은 수상/파트너십

## API 출력 구조

AI 편집 API는 HTML이 아니라 구조화된 JSON을 반환하는 것이 좋다.

```json
{
  "title": "string",
  "intro": ["string"],
  "contents": ["01 발신 배경", "02 진단 결과"],
  "sections": [
    {
      "no": "01",
      "title": "발신 배경",
      "body": ["string"]
    }
  ],
  "followup": "string"
}
```
