# SalesKit AI Research Pack

SalesKit AI를 영업용 콜드메일 제작 도구로 검증하기 위해 참고할 공개 GitHub Markdown 자료와, 제품에 바로 반영할 운영 가이드를 정리한 문서 묶음입니다.

## 구성

- `source-index.md`: 참고한 공개 GitHub 자료 목록과 적용 포인트
- `saleskit-agent-guidelines.md`: SalesKit AI용 에이전트 지침 초안
- `cold-email-template-structure.md`: 제안형 콜드메일 생성 구조
- `ai-editing-rules.md`: 사용자의 수정 요청을 처리하는 AI 편집 규칙
- `email-html-compatibility.md`: Gmail, 네이버메일, 다음메일 붙여넣기용 HTML 기준
- `marketing-sales-agent-patterns.md`: 마케팅/영업 에이전트 자료에서 가져온 제품 패턴

## 사용 방식

이 폴더는 그대로 GitHub 저장소의 `docs/research/` 또는 `docs/saleskit/` 아래에 올릴 수 있습니다.

권장 경로:

```text
docs/saleskit/
  README.md
  source-index.md
  saleskit-agent-guidelines.md
  cold-email-template-structure.md
  ai-editing-rules.md
  email-html-compatibility.md
  marketing-sales-agent-patterns.md
```
