# Cold Email Template Structure

SalesKit AI의 기본 메일은 단순한 콜드메일이 아니라 "제안서형 콜드메일"이다.

## 기본 구조

```text
타이틀

인사 및 발신 배경

목차
01 발신 배경
02 진단 결과
03 핵심 솔루션
04 기대 효과
05 미팅 제안

01 발신 배경
본문

02 진단 결과
본문

03 핵심 솔루션
본문

04 기대 효과
본문

05 미팅 제안
본문

명함
```

## 왜 이 구조인가

영업 사원이 보내는 제안 메일은 짧기만 하면 설득력이 부족하고, 너무 길면 읽히지 않는다.

목차형 구조는 다음 장점이 있다.

- 상대가 빠르게 훑어볼 수 있음
- "사전 분석했다"는 인상을 줌
- 제안서보다 가볍고 일반 콜드메일보다 전문적으로 보임
- 이후 PPT 제안서로 확장하기 쉬움

## 섹션별 작성 기준

### 타이틀

형식:

```text
[업체명] 검색 노출 구조 진단 및 개선 제안
[업체명] 사전 진단 결과 기반 제안드립니다
[업체명] 대표님께 짧은 개선 제안드립니다
```

원칙:

- 업체명 포함
- 제안 내용을 한 줄로 명확하게 표현
- 과장 금지

### 인사 및 발신 배경

목표:

- 왜 연락했는지 설명
- 상대 업체를 보고 작성했다는 느낌 제공

예시 구조:

```text
안녕하세요, 담당자님.
[업체명]의 공개된 웹사이트와 제안 가능 포인트를 기준으로 간단히 살펴본 결과, 공유드릴 만한 개선 방향이 있어 연락드립니다.
이번 메일은 [제안 서비스] 관점에서 바로 확인하실 수 있도록 핵심만 목차 형태로 정리했습니다.
```

### 목차

고정 구조:

```text
01 발신 배경
02 진단 결과
03 핵심 솔루션
04 기대 효과
05 미팅 제안
```

### 01 발신 배경

포함할 내용:

- 시장 변화
- 상대 업체가 신경 써야 할 이유
- 지금 연락한 이유

### 02 진단 결과

포함할 내용:

- URL 또는 공개 정보 기준 진단
- 점수 또는 관찰 포인트
- 개선 여지

주의:

- 실제 크롤링/분석 전에는 확정적인 표현 금지

### 03 핵심 솔루션

포함할 내용:

- 제안 서비스의 역할
- 작은 테스트 방식
- 실행 흐름

### 04 기대 효과

포함할 내용:

- 시간 절감
- 전환 개선
- 반복 작업 감소
- 영업 준비 효율화

### 05 미팅 제안

포함할 내용:

- 짧은 미팅 요청
- 상대가 회신하기 쉬운 문장

예시:

```text
가능하시다면 15분 정도 짧게 이야기 나누고, [업체명]에 적용 가능한 방향을 공유드리고 싶습니다.
편하신 일정 회신 주시면 맞춰서 간단히 설명드리겠습니다.
```

### 명함

포함할 내용:

- 이름/직함
- 회사명
- 전화번호
- 이메일
- 주소 또는 신뢰 요소
