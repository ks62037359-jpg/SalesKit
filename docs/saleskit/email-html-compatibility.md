# Email HTML Compatibility

SalesKit AI의 HTML 결과물은 웹페이지가 아니라 메일 작성창에 붙여넣기 위한 본문이다.

## 우선 지원 플랫폼

- Gmail
- 네이버메일
- 다음메일
- Outlook 웹메일

## 생성 규칙

- 외부 CSS 사용 금지
- `<style>` 태그 의존 금지
- class 기반 스타일 의존 금지
- JavaScript 사용 금지
- flex/grid 의존 금지
- table layout 사용
- inline style 사용
- 이미지 없이도 읽히는 구조 우선
- CTA는 실제 `<button>`이 아니라 스타일이 적용된 텍스트 또는 링크 형태

## 복사 규칙

복사 버튼은 HTML 코드 원문을 복사하면 안 된다.

우선순위:

1. `text/html`과 `text/plain`을 함께 클립보드에 저장
2. 브라우저가 막으면 숨겨진 리치 본문을 선택 복사
3. 그래도 실패하면 텍스트 본문만 복사

## 테스트 체크리스트

### Gmail

- 본문 붙여넣기 시 HTML 코드가 보이지 않는가
- 표 구조가 깨지지 않는가
- 제목, 목차, 섹션, 명함이 구분되는가

### 네이버메일

- inline style이 유지되는가
- 목차 박스와 섹션 제목이 읽히는가
- 복사한 본문이 과하게 넓어지지 않는가

### 다음메일

- 본문 색상과 여백이 과하게 제거되지 않는가
- 명함 정보가 정상 표시되는가

## 디자인 원칙

화려한 카드형 디자인보다 아래를 우선한다.

- 읽기 쉬운 본문
- 명확한 목차
- 짧은 섹션
- 안전한 여백
- CTA 문장의 명확성
